# اختبار نسخة مِيزان على أندرويد قبل التوزيع

1. نزّل `mizan-debug-apk` من GitHub Actions، وسجّل رقم الالتزام والجهاز وإصدار أندرويد.
2. خذ نسخة JSON من الإصدار القديم. سجّل معاملة وابدأ وردًا، ثم حدّث فوقه **بنسخة تحمل نفس شهادة التوقيع**. حزم Debug من تشغيلات مختلفة في GitHub Actions قد تحمل مفاتيح مختلفة، فلا تعتبر رفض التثبيت مشكلة ترقية بيانات. لا تحذف النسخة القديمة دون نسخة احتياطية.
3. افتح التطبيق في وضع الطيران. افحص بقاء البيانات والمفضّلة، واستئناف نفس المجموعة والعنصر عبر «تابع وردك».
4. سجّل مصروفًا: المبلغ أولًا، المحفظة الأخيرة، وتغيير التاريخ والملاحظات من التفاصيل. جرّب الحفظ بضغطتين متقاربتين، وتأكد أن السجل يحتوي على معاملة واحدة.
5. فعّل قفل الميزانية، واختبر اختصار المصروف والودجت بعد انتقال التطبيق للخلفية. يجب ألّا تظهر المبالغ قبل فتح القفل.
6. اختبر التسبيح بزر الصوت والهاتف مقفل، والتذكير بعد إعادة التشغيل. افحص أن معاينة النسخة تعرض التاريخ والأقسام والأعداد قبل الاستعادة.

لا توزّع النسخة قبل تسجيل نتائج الاختبارات أعلاه على جهاز فعلي. نجاح البناء ليس بديلًا عن اختبار التحديث.
