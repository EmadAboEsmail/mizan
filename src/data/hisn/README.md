# حصن المسلم — مصدر المكتبة

نسخة القراءة من [`asellam/HisnElMuslim`](https://github.com/asellam/HisnElMuslim/tree/872764ca013116c905f7fc9c3dc972c27cd37d4a)، ملف `hisn.json`، بترخيص المستودع MIT المرفق. أبقينا ترتيب الأبواب ونص `Text` والمراجع والأعداد الرقمية دون تحرير. حُذفت روابط الصوت الخارجية.

المحتوى ليس تحقيقًا مستقلًا. قد يتضمن المدخل شرحًا أو صيغة بديلة. العدد الرقمي المحفوظ لأغراض المراجعة لا يُستخدم كهدف للتكرار ولا يُعرض كعدد وارد. المكتبة للقراءة فقط ولا تضيف شيئًا تلقائيًا إلى قاعدة بيانات المستخدم أو عدّاد التسبيح.
